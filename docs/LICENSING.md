# Media Licensing & Intellectual Property Standards: Khmer Heritage

## 1. Licensing Principles
Because Khmer Heritage is a dedicated educational and cultural production platform intended for global distribution (Android, iOS, Web), strict compliance with copyright and intellectual property law is mandatory.

## 2. Permitted License Tiers (Prioritized)
1. **Public Domain (PD)**: Expired copyright (e.g. 19th and early 20th century historical photographs, archival drawings).
2. **Creative Commons Zero (CC0)**: Dedicated to public domain without restriction.
3. **Creative Commons Attribution (CC BY)**: Attribution required, commercial reuse allowed.
4. **Creative Commons Attribution-ShareAlike (CC BY-SA)**: Attribution and share-alike required.
5. **Original In-House / Commissioned**: Custom photography, vector diagrams, and original audio created specifically for the project.
6. **Direct Written Permission**: Explicit commercial and non-commercial license grant from the rights holder.

## 3. Restricted & Prohibited Media
- **Strictly Prohibited**:
  - Unlicensed images scraped from Google Images, Pinterest, Facebook, Instagram, TikTok, YouTube.
  - "Free download" or "Free to watch" websites without explicit commercial license terms.
  - Watermarked stock imagery without valid enterprise license.
- **Avoided**:
  - Creative Commons Non-Commercial (CC BY-NC) licenses, unless explicitly authorized for non-monetized educational sub-modules, to avoid legal entanglement in production app store distribution.

## 4. Required Attribution Fields per Media Asset
Every media item cataloged in the system MUST include:
- Author / Creator Name
- Source Organization / Repository
- Source URL
- License Type Identifier
- Official License Terms URL
- Required Attribution Text
